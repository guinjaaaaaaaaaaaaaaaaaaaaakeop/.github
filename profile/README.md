# guinjaaaaaaaaaaaaaaaaaaaaakeop

Five independent plugins for LLM-era development. Each locks one discipline into the workflow;
none knows the others exist; any subset composes.

| plugin | what it holds |
|---|---|
| [hunsu](https://github.com/guinjaaaaaaaaaaaaaaaaaaaaakeop/hunsu) | the environment — declared, judged for conflicts, locked like dependencies |
| [chongdae](https://github.com/guinjaaaaaaaaaaaaaaaaaaaaakeop/chongdae) | the work — every change inside a run; judgments notarized as git commits |
| [dakdol](https://github.com/guinjaaaaaaaaaaaaaaaaaaaaakeop/dakdol) | the build — a fresh process implements a slice from its brief, contract tests protected |
| [mangsang](https://github.com/guinjaaaaaaaaaaaaaaaaaaaaakeop/mangsang) | the meaning — concepts as first-class nodes; plan, code and tests as their projections; drift detected by fingerprint, answered by judgment |
| [dwitbuk](https://github.com/guinjaaaaaaaaaaaaaaaaaaaaakeop/dwitbuk) | the review — late eyes over the record; observations kept, objections owed |

Install any of them directly — each repository is its own marketplace:

```
claude plugin marketplace add guinjaaaaaaaaaaaaaaaaaaaaakeop/hunsu
claude plugin install hunsu@hunsu
```

All five follow semver; a version names one content. A worked-example repository
(the whole loop on a real project, with its full notarized record) is being prepared.
